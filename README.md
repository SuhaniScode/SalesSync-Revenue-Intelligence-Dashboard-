An end-to-end data analytics project built on an e-commerce dataset to uncover revenue patterns, customer behavior, and regional performance.
This project simulates real-world business analysis using SQL and dashboarding tools.

📊 Business Problem

Businesses often struggle to understand:

Where revenue is coming from
Who their most valuable customers are
Which regions drive the most sales
How sales change over time

This project answers these using structured data analysis.

Identified top revenue-generating states
Analyzed customer purchase frequency & spending
Evaluated order status distribution
Tracked monthly sales trends
Calculated total revenue including logistics cost
🧠 SQL Analysis Highlights
Revenue = Price + Freight calculation
Multi-table joins (orders, customers, items)
Aggregations & grouping
Time-series analysis using timestamps
